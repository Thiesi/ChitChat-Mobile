## State and application contract

- One original foreground pane binds server/account/generation/session version, room-or-peer namespace and actual current navigation entry ID. Selection, candidate and request references additionally bind a complete UTF16 draft/caret snapshot. New owner/entry/name/target retires old GET work; late success/error/finally, close, retry or cleanup cannot affect successors. A rejecting draft consumer keeps its choice; a reentrant accepted consumer keeps its new pane.
- Active IME composition, non-collapsed/out-of-range selection and non-token caret positions suppress completion. Applying a choice preserves every prefix/suffix code unit and places the caret after the insertion. A final newline is after a token, not its old caret. IRC cycles preserve the original suffix and source order with case-insensitive deduplication; initial plain names get addressing punctuation, other positions a space. No matching local name means no Tab action.
- Room @choices combine explicit `room`/`here` broadcasts and server hints, at most8. Reserved names returned as account hints remain labeled/deduplicated broadcasts, without invented IDs. Both keywords resolve across eligible members, never online-only @here. DM uses only the original peer/name, with no room/global lookup or broadcast conversion; room ignore is not DM block.
- The25-member seed is attempted once per pane; failure retains local speaker/presence fallback with no retry loop. Prefix edits debounce150ms and only obsolete safe GETs are cancelled. Failed prefix GETs require explicit Refresh suggestions with a new selection/request reference. Repeated foreground/bind retains configuration work and does not replay queries. Genuine background/owner/navigation retirement drops private choices and hints, without touching feature-owned drafts or POSTs.
- Choice/Tab methods only propose a complete draft to a feature-owned accepting callback. They cannot send, acknowledge read, publish typing, alter policy, or modify uncertain-delivery/reconciliation/duplicate-risk flags. Private drafts/names/prefixes/selection/work have no saved/disk/log state or generated content string representation. Bounds are8 picker choices,25 room seed names and1,024 local cycle inputs.
