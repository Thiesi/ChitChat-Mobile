Optional room context is not membership/history permission. ignored/moderation enrichment is not adopted as session policy, and can_remove_avatar/avatars_available are read-only hints, never a management/step-up capability. No image URL is invented and no removal, ignore, moderation, read/send or account mutation is available through this interface.
