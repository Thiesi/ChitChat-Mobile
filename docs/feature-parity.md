# Feature-parity matrix

[M5g4a room attachment drafts](milestones/M5g4a-room-attachment-draft-state.md) connects local preparation to the real room VM, original private slots, existing100-draft capacity and a process-scoped memory ledger. Navigation/background may finish only in the original private slot; display/actions need fresh entry proof. Replacement/discard/session retirement rejects late results and preserves charges until actual producer end. DM ownership, final policy checks, consent, upload and native picker/card controls remain pending; this is not usable files/media acceptance.

[M5g3i owned preparation](milestones/M5g3i-owned-preparation-task.md) adds an internal one-shot producer with pre-open reservation, conservative retained-byte charges and synchronous original-task adoption/discard. It does not yet connect actual app picker/draft/process ownership or expose file controls. No silent raw-photo fallback, send consent, provider acceptance or cancellation/non-delivery claim is added.

[M5g3h memory reservations](milestones/M5g3h-attachment-memory-budget.md) adds an internal shared-capacity lease primitive with atomic growth/release and stale-lease protection. It does not yet bound actual app allocations: process ownership, correct buffer costing, original-owner attachment state and native/provider consumers must adopt it. No usable media control, send consent or cancellation/non-delivery claim is added.

[M5g3e WebP privacy](milestones/M5g3e-webp-photo-privacy.md) adds internal static-WebP metadata cleanup preserving coded pixels, ICC, alpha and supported orientation/colour, with original RIFF/feature validation and known raw/prefixed TIFF handling. JVM container regressions and a real Android codec test distinguish byte retention from decoder proof. Animation/unknown layouts remain safe failures; final ready-byte hashing, aggregate memory/state, explicit failure consent/fallback and native/provider controls remain pending. This is not complete photo/files/media acceptance.

[M5g3d PNG privacy](milestones/M5g3d-png-photo-privacy.md) adds internal bounded static-PNG metadata removal, keeping supported orientation/colour, coded pixels, palette/transparency, colour/HDR and aspect data. JPEG reuses the same bounded TIFF helper with unchanged regressions. APNG, unknown extensions and unproven metadata orientation fail safely; they are never flattened or silently sent. WebP, safe fallback/explicit failure consent, final ready-byte hash, aggregate attachment memory/state and native/provider controls remain pending; this does not complete P-157 or files/media.

[M5g3c JPEG colour metadata](milestones/M5g3c-jpeg-colour-metadata.md) extends the internal JPEG rewrite to retain the exact standard EXIF colour-space value and known R98/R03 interoperability/version fields, including uncalibrated colour backed by an unchanged ICC profile. It neither invents a profile nor changes coded image bytes. Calibration, unknown interoperability and malformed layouts still fail safely. PNG/WebP, fallback/explicit failure consent, final cleaned-byte readiness/hash, provider/native controls and complete photo acceptance remain pending.

[M5g3b JPEG privacy](milestones/M5g3b-jpeg-photo-privacy.md) adds the bounded ordinary-JPEG metadata rewrite, removing private metadata while retaining valid orientation, coded scans and recognised colour markers. M5g3c extends its initially conservative EXIF colour support; neither foundation is a usable native attachment control or upload consent.

[M5g3a picked-file snapshot](milestones/M5g3a-picked-file-snapshot.md) adds internal bounded single-read raw preparation, immutable bytes, safe failures and cancellation fences. This creates no upload-ready photo, reconciliation digest, picker/provider adapter or usable native media control. Photo cleaning and cleaned-byte evidence remain pending.

[M5g2b upload protocol](milestones/M5g2b-attachment-upload-protocol.md) adds internal explicit room/DM multipart using original-session capabilities, immutable prepared bytes and one-use attempts. Confirmed message IDs precede optional enrichment; no write is replayed. Preparation/photo cleaning, serialized attachment state, native media/sharing and live acceptance remain pending.

[M5g2a refusal metadata](milestones/M5g2a-attachment-refusal-metadata.md) retains bounded size/rate hints from existing HTTP errors without another request or native controls. Unknown/zero limits stay distinct, invalid optional hints preserve the refusal, and no write is replayed. Upload transport, attachment state and usable media/sharing remain pending.

[M5g1 attachment policy](milestones/M5g1-attachment-policy.md) brings the released upload-policy facts into generation-scoped session memory through the existing bootstrap. Missing, null and zero remain distinct; an unusable advertised policy disables uploads without blocking session bootstrap. Refresh and retirement cannot retain obsolete policy. This prerequisite adds no upload, download, picker, image or sharing control, and grants no upload permission. Native files/media and live/provider/device acceptance remain pending.

[Standalone IME measurements](milestones/standalone-ime-reproducer.md) add no product parity: opt-in app/server-free diagnostic APKs, fifty fresh-window cases per authorized arm, separate from ordinary native gates and real-device/live/release acceptance.

Local System/Light/Dark and Pure black, token-based controls/type, icons and the actual default/200% capture matrix are implemented. ownership, reconciliation choices and native controls remain pending. This is no
new user-facing attachment capability or live/provider acceptance.

or an original-bound privacy choice. Unsupported images never become ready raw
files automatically. Native choice/owner/budget state and attachment controls remain
pending; this core prerequisite adds no user-facing picker or send capability.
