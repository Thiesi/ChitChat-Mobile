### M3c3 canonical room-consumer constraints

PR20's canonical reader now has the [M3c3b native consumer](milestones/M3c3b-room-realtime.md). M3 stays unchecked pending authorized live acceptance. Continue autonomously into M4; missing live-room permission does not block its independent work.

Do not reuse the current `ConversationViewModel.request()/reload()` for automatic event reconciliation: they replace the newest50 window, discard busy invalidations, alter uncertain-send reconciliation and cancel read POSTs. Add generation/room-scoped pending/applied invalidation revisions, drain/coalesce after existing operations, and keep automatic GETs distinct from explicit unknown-delivery reconciliation. Never cancel/replay send/read POSTs to serve an event. Read callbacks need an independent identity/room/read sequence; viewport visibility remains the only read-eligibility authority. Consumer cancellation/recreation and failed reductions must retain the need for canonical reconciliation, not treat a buffered event as applied history.

Use existing history for a bounded canonical range, not a guessed endpoint or mutation-only refresh: mutations preserve old reply/attachment objects. `history(before_id=loadedUpperId+1,limit=100)` starts directly at an older window; guard overflow. Follow strictly decreasing **raw** pagination cursors toward the captured lower boundary, at most six pages/600 raw rows; empty enriched pages are not exhaustion. Fresh history hydrates off-window quoted targets and attachments before exact-ID metadata enrichment. These bounds/snapshot fields are client-derived, not invented server fields.

Only adopt/merge a latest range after coverage/overlap is established. Keep at most500 rows; preserve raw pagination boundaries, anchor ID/offset, draft, uncertain-send flags, unread divider, read cursor/attempt/error state. Away from the live edge, bounded non-overlap must refresh the fixed old range and offer explicit New messages/Jump latest, never silently stitch disjoint ranges or force-scroll. Retention losing an anchor needs a neighbouring survivor and an explanation; incomplete coverage remains visibly stale with Retry/Jump latest. Confirmed permission loss clears inaccessible content; CSRF/network/rate errors preserve it. Ordinary edits/reactions are not new unread messages.

Regression gates include older-range direct access, off-window quote edit/delete/removal, omitted enriched pages with progressing raw cursor, retention/anchor loss, latest overlap/non-overlap, invalidations during send/read/older loading, own event before POST acknowledgement, unchanged unknown-delivery consent/read errors/divider, late account/room callbacks and bounded coalescing without failure retry loops. Then wire native presence eligibility/warnings/Stay/Return and acknowledged-send activity; no typing/scroll-based activity or passive background/network reentry.
